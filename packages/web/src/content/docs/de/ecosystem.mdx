---

Eine Sammlung von Community-Projekten, die auf OpenResearch basieren.

:::note
Möchten Sie Ihr OpenResearch-bezogenes Projekt zu dieser Liste hinzufügen? Senden Sie einen PR.
:::

Sie können sich auch [awesome-openresearch](https://github.com/awesome-openresearch/awesome-openresearch) und [openresearch.cafe](https://openresearch.cafe) ansehen, eine Community, die das Ökosystem und die Community zusammenfasst.
