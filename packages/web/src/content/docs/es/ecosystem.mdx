Una colección de proyectos comunitarios construidos en OpenResearch.

:::note
¿Quieres agregar tu proyecto relacionado con OpenResearch a esta lista? Envíe un PR.
:::

También puedes consultar [awesome-openresearch](https://github.com/awesome-openresearch/awesome-openresearch) y [openresearch.cafe](https://openresearch.cafe), una comunidad que agrega el ecosistema y la comunidad.
