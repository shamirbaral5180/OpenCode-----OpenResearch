---

ชุดโครงการชุมชนที่สร้างขึ้นบน OpenResearch

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ OpenResearch ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-openresearch](https://github.com/awesome-openresearch/awesome-openresearch) และ [openresearch.cafe](https://openresearch.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
